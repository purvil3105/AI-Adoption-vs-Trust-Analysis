# Power BI build guide (about 30–45 minutes)

Everything the report needs is already prepared. This guide walks through rebuilding it in **Power BI Desktop (free)**. A ready-to-use interactive version of the same dashboard is in `dashboard/ai_trust_dashboard.html`. Open it in any browser; it needs no install or account.

> Why a guide and not a `.pbix` file? A `.pbix` can only be authored inside the Power BI Desktop interface, which was not available on the build machine. Every input below is generated by the pipeline, so the report is fully reproducible.

## 0. Prerequisites
1. Install **Power BI Desktop** from the Microsoft Store (free).
2. Run the pipeline once (`python run_pipeline.py`) so that `data/processed/powerbi/` contains the CSV files.

## 1. Load the data (Home → Get data → Text/CSV)
Load these files from `data/processed/powerbi/`:

| File | Role | Notes |
|---|---|---|
| `fact_respondents.csv` | Fact table | one row per respondent per year (203,812 rows) |
| `bridge_ai_tasks.csv` | Bridge | what each respondent uses AI for |
| `bridge_ai_tools.csv` | Bridge | AI products / models / AI editors used |
| `bridge_ai_frustrations.csv` | Bridge | 2025 frustrations |
| `dim_year.csv`, `dim_experience.csv`, `dim_org_size.csv`, `dim_role.csv`, `dim_country.csv`, `dim_trust.csv` | Dimensions | used for slicers and sort order |
| `agg_segment_metrics.csv`, `agg_task_trust.csv`, `agg_tool_trust.csv`, `agg_headline.csv` | Pre-aggregated (from DuckDB SQL) | optional; handy for quick visuals |

In Power Query, check these column types: `uses_ai`, `trusts_ai`, `distrusts_ai`, `frus_*` = **Decimal number** (blank = not asked or not answered); `survey_year` = **Whole number**.

## 2. Model view: relationships
| From (many) | To (one) | Filter direction |
|---|---|---|
| `fact_respondents[survey_year]` | `dim_year[survey_year]` | Single |
| `fact_respondents[exp_bucket]` | `dim_experience[exp_bucket]` | Single |
| `fact_respondents[org_size]` | `dim_org_size[org_size]` | Single |
| `fact_respondents[role_family]` | `dim_role[role_family]` | Single |
| `fact_respondents[country]` | `dim_country[country]` | Single |
| `fact_respondents[trust_label]` | `dim_trust[trust_label]` | Single |
| `bridge_ai_tasks[resp_id]` | `fact_respondents[resp_id]` | **Both** |
| `bridge_ai_tools[resp_id]` | `fact_respondents[resp_id]` | **Both** |
| `bridge_ai_frustrations[resp_id]` | `fact_respondents[resp_id]` | **Both** |

Sort-by-column settings: `dim_experience[exp_bucket]` by `sort_order`, and `dim_org_size[org_size_label]` by `sort_order`.

## 3. Measures
Create an empty table `_Measures`, then paste every measure from **`DAX_measures.dax`**. Format the `%` measures as Percentage with 1 decimal place.

## 4. Theme
View → Themes → Browse for themes → `theme_ai_trust.json`. This is the colour-blind-checked palette used in the Python charts: adoption = blue, trust = aqua, distrust = orange.

## 5. Report-level filter
Filters pane → *Filters on all pages* → `fact_respondents[is_professional]` = 1.

## 6. Pages

| Page | Visuals |
|---|---|
| **1 Overview** | 3 cards for 2025 values (`Adoption %`, `Trust %`, `Distrust %`) plus `Distrust change vs 2023 (pp)`. A line chart with X = `dim_year[survey_year]` and Y = `Adoption %`, `Trust %`, `Distrust %`, with data labels on. A text box stating the base: "Trust among current AI users". |
| **2 Who trusts AI** | Slicer: `dim_year`. A clustered bar chart with Y = `dim_experience[exp_bucket]`, Legend = `dim_year[survey_year]`, X = `Distrust % (n>=100)`. Repeat for role, company size and country (top 15 = `country_group`). A scatter chart with Details = `role_family`, X = `Adoption %`, Y = `Distrust %`, Size = `Trust Base (AI users)`. |
| **3 How AI is used** | A bar chart with Y = `bridge_ai_tasks[task]`, Legend = year, X = `Distrust % (n>=100)`. A column chart with X = `fact_respondents[ai_use_frequency]` (2025), Y = `Distrust %`. A bar chart by `ai_agents`. |
| **4 Why distrust (2025)** | Year filter = 2025. A bar chart with Y = `bridge_ai_frustrations[frustration]`, X = count of `resp_id` ÷ `Frustration Base`. Cards for `Distrust % | reports debugging slower` vs `Distrust % | no debugging complaint`. An image of `reports/figures/fig12b_forest_2025.png` (the regression forest plot). |
| **5 Method & caveats** | Text: sources, base definitions, comparability tiers, self-selection warning. A table visual of `mappings/question_crosswalk.csv` (load it as an extra table). |

Tooltips: add `Trust Base (AI users)` to every visual's tooltip so the n is always visible.

## 7. Publish (free options)
- **Free:** File → Export → **PDF**, plus screenshots for the README.
- "Publish to web" requires a Power BI work or school account. If you don't have one, share the PDF and the HTML dashboard instead.
- **Alternative with a free public link:** Tableau Public. The same CSVs load directly.
